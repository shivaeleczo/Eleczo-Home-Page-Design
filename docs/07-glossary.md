# Glossary

Written so that a frontend or SEO agent with no electrical-trade background does not
misread a requirement. Trade vocabulary is not decoration — it is how buyers search.

## Trade

| Term | Meaning |
|---|---|
| MCB | Miniature Circuit Breaker — low-current protective device, residential and light commercial |
| MCCB | Moulded Case Circuit Breaker — higher current rating, adjustable trip settings |
| ACB | Air Circuit Breaker — high-current, typically main incomer in an LV panel |
| RCCB / RCBO | Residual Current device — earth-leakage protection; RCBO adds overcurrent protection |
| Contactor | Electrically operated switch for motor and load control |
| Switchgear | Collective term for protection, isolation and control devices |
| Distribution board (DB) | Enclosure distributing supply to final circuits |
| Panel builder | Assembles electrical control/distribution panels to order — buys by BOM, multi-line |
| OEM | Buys components to build into their own manufactured equipment — repeat, scheduled |
| Breaking capacity (kA) | Maximum fault current a device can interrupt safely — a hard selection criterion |
| Pole count | 1P/2P/3P/4P — number of switched conductors; a hard selection criterion |
| BOM | Bill of Materials — the line-item list a panel builder purchases against |
| MRP | Maximum Retail Price — printed ceiling price, regulated in India |

## Platform

| Term | Meaning |
|---|---|
| FPC | Magento Full Page Cache |
| Hole-punching | Serving a cached page with small dynamic regions filled separately (ESI or private content) |
| ESI | Edge Side Includes — Varnish mechanism for per-block caching |
| Private content | Magento's customer-specific data fetched client-side to keep pages cacheable |
| Page Builder | Magento's WYSIWYG content authoring tool |
| Hyvä | Alternative Magento frontend theme, markedly lighter than Luma |
| Luma | Magento's default frontend theme |

## Measurement

| Term | Meaning |
|---|---|
| LCP | Largest Contentful Paint |
| INP | Interaction to Next Paint |
| CLS | Cumulative Layout Shift |
| Field data | Real-user measurement (e.g. CrUX), as opposed to synthetic lab testing |
