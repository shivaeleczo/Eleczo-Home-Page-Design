## Purpose

Every numerical, comparative and superlative claim Eleczo currently publishes about itself, recorded with its source and its conflicts.

> **No value has been selected.** Where sources disagree, both figures are recorded and neither is preferred. Choosing between them is a substantiation question for Eleczo, not an editorial question for this project. A claim register that quietly picks the larger number is worse than no register at all.

## Binding constraint on all agents

> **CC-01 — `MUST NOT`.** No claim in this register may appear in homepage copy, metadata, structured data, imagery or any other deliverable until its status here is `SUBSTANTIATED` and an approver is named. This binds the content agent, the SEO agent and the graphic design agent equally. A claim carried in an image is still a claim.

## Status definitions

| Status | Meaning |
|---|---|
| `CONFLICTED` | Eleczo publishes two or more different values across its own properties |
| `UNSUBSTANTIATED` | Single value published, no basis or as-at date identified |
| `SUPERLATIVE` | Comparative market-position claim requiring evidence of the comparison |
| `SUBSTANTIATED` | Confirmed by Eleczo with a basis and an as-at date — **none yet** |
| `RETIRED` | Withdrawn from use |

### CLM-01 — Brand count

| | |
|---|---|
| **Status** | `CONFLICTED` |
| **Value A** | "50+ brands" |
| **Value B** | "40+ top brands" |
| **Value C** | "50+ Global Brands" |
| **Sources** | A: eleczo.com homepage copy · B: mohanexim.com/eleczo · C: Eleczo Instagram profile |
| **Risk** | Medium — a factual claim about assortment, verifiable against the catalogue |
| **Resolution needed** | Actual count of brands with live, purchasable SKUs, as at a stated date. Distinguish "brands carried" from "brands authorised to sell" — the latter is the stronger and safer claim |

### CLM-03 — Years of experience

| | |
|---|---|
| **Status** | `CONFLICTED` |
| **Value A** | "57 years excellence in the electrical industry" |
| **Value B** | "over 50+ years in the electrical industry" |

## Section B — Unsubstantiated single-source claims

### CLM-04 — Certified seller count

| | |
|---|---|
| **Status** | `UNSUBSTANTIATED` |
| **Value** | "600+ certified sellers" |
| **Source** | eleczo.com homepage copy |
| **Risk** | **Medium-High** — the word *certified* implies a verification process |
| **Resolution needed** | Active seller count as at a stated date, **and** what "certified" means operationally: what is verified, by whom, against what standard. If no defined certification process exists, the word must be removed |
| **Note** | For public sector buyers (AUD-4) this claim is load-bearing — procurement processes may treat "certified" as a compliance assertion |

### CLM-05 — Customer satisfaction

| | |
|---|---|
| **Status** | `UNSUBSTANTIATED` |
| **Value** | "100% customer satisfaction" |
| **Source** | eleczo.com homepage copy |
| **Risk** | **High** |
| **Resolution needed** | No realistic substantiation exists. Public review platforms carry both strongly positive and strongly negative Eleczo reviews, which directly contradicts a 100% claim |
| **Recommendation** | **Retire.** A "100% satisfaction" claim is unverifiable, contradicted by publicly visible reviews, and reads as unserious to professional buyers. Replace with a specific service commitment that can actually be met |

### CLM-06 — Product quality and assurance claims

| | |
|---|---|
| **Status** | `UNSUBSTANTIATED` |
| **Values** | "world-class electrical products" · "assured products" · "products are verified" · "best qualitative and assured products" |
| **Source** | eleczo.com, RocketReach profile |
| **Risk** | **Medium-High** — "verified" and "assured" imply a quality process |
| **Resolution needed** | What verification actually occurs — authenticity checks, certification validation, seller vetting, inspection? Against what standard, by whom? |
| **Note** | In electrical products, quality and authenticity claims carry safety implications. Counterfeit protective devices are a real market problem, so a substantiated authenticity claim is genuinely valuable — and an unsubstantiated one is a genuine liability |

### CLM-07 — Delivery and service claims

| | |
|---|---|
| **Status** | `UNSUBSTANTIATED` |
| **Values** | "deliver at customized time" · "order 24/7" · "to your doorstep" · free shipping threshold and named logistics partner (customer-reported) |
| **Source** | eleczo.com; fulfilment specifics from public customer reviews, not from Eleczo |
| **Risk** | Medium |
| **Resolution needed** | Actual service terms: delivery timeframes, coverage, shipping threshold, payment methods (including whether COD is offered), returns and cancellation policy |
| **Note** | Public reviews include complaints about delivery and about the absence of a visible cancellation route. Homepage service claims that contradict operational reality damage trust faster than making no claim. Linked to DS-19 |

## Section C — Superlative and market-position claims

### CLM-08 — "India's Largest Online Electrical Store"

| | |
|---|---|
| **Status** | `SUPERLATIVE` |
| **Value** | "India's Largest Online Electrical Store" — used as a primary strapline |
| **Sources** | eleczo.com, mohanexim.com, Instagram, YouTube |
| **Risk** | **High** |
| **Why** | A comparative market-position claim requires evidence of the comparison — largest by what measure (SKUs, revenue, sellers, traffic, coverage), against which competitor set, as at what date, from what source? India's consumer-protection framework treats unsubstantiated advertising claims as actionable, and comparative superlatives are the most exposed category |
| **Resolution needed** | Either documented evidence supporting the specific measure, or retirement |
| **Recommendation** | For a trade audience this claim is also **commercially weak**. Professional buyers discount superlatives reflexively; specific verifiable facts — founding year, named brand authorisations, seller count with a definition, certifications — build more confidence and carry less risk. This is the rare case where the safer option is also the more persuasive one |

### CLM-09 — "India's best" / "most trusted" variants

| | |
|---|---|
| **Status** | `SUPERLATIVE` |
| **Values** | "India's best online electrical shopping store" · "India's best and most trusted online electrical e-commerce portal" · "India's reliable and preferred online destination" · "one of the best electrical product suppliers" |
| **Sources** | eleczo.com, mohanexim.com, Crunchbase profile |
| **Risk** | **High** — same category as CLM-08; "most trusted" is the most exposed, implying measured comparative trust |
| **Resolution needed** | Evidence, or retirement |
| **Recommendation** | Retire all variants. Note these appear in **third-party profiles** (Crunchbase, RocketReach) as well as owned properties — retirement requires updating syndicated profiles too, or the claims persist in search results and AI-generated summaries |

### CLM-10 — Manufacturer brand names and logos

| | |
|---|---|
| **Status** | `UNSUBSTANTIATED` (authorisation status unknown) |
| **Values** | Named use of Havells, Siemens, Schneider Electric, L&T, Socomec and others |
| **Risk** | **High** if logos are displayed without authorisation |
| **Resolution needed** | Per-brand confirmation of authorised-partner status and permitted logo usage, including any placement obligations under distribution agreements (D-4) |
